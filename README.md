# Dotfiles – Hyprland

Personal dotfiles with [Material Design](https://m3.material.io/) colors generated by [Matugen](https://github.com/InioX/matugen) based on the wallpaper, along with configuration files for applications and the [Hyprland](https://hypr.land/) compositor.

<br>

## Installation using [YADM (Yet Another Dotfiles Manager)](https://yadm.io/)

```bash
sudo pacman -S --needed yadm
yadm clone https://github.com/DimitryGonzales/dotfiles-hyprland.git
yadm checkout --force
```

> [!CAUTION]
> This will overwrite existing config files that share the same paths as the ones in this repository.
